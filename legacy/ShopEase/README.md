# ShopEase 🛍️

A fully responsive e-commerce web application with product search & filtering, cart management, wishlist, and persistent local storage.

## Features
- 🔍 Live product search
- 🗂️ Category filtering (Electronics, Fashion, Home, Sports)
- 🛒 Cart with quantity management & persistent state (localStorage)
- ❤️ Wishlist toggle
- 💰 Sort by price, rating
- 📱 Fully responsive design
- 🎨 Dark, modern UI with smooth animations

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- localStorage for persistent cart & wishlist
- Google Fonts (Syne + DM Sans)
- CSS Variables for theming

## Getting Started
```bash
# Just open in browser — no build step needed!
open index.html
# OR serve with a local server:
npx serve .
```
